# sitereal-xcloud-demo

A minimal Astro 7 site shaped like a [sitereal](https://sitereal.app) project, used to test hosting sitereal sites on [xCloud](https://xcloud.host).

- `main`: static build (`npm run build` → `dist/`)
- `ssr`: `@astrojs/node` adapter, runs with `node ./dist/server/entry.mjs`
